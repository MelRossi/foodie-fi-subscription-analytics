04 · Segmentación conductual de clientes¶

Proyecto: Análisis de clientes de un servicio de suscripción (Foodie-Fi) · Etapa 4 de 5 Entrada: datasets limpios del notebook 01 y métricas de los notebooks 02 y 03 (reports/metrics/)

Preguntas de negocio que responde este notebook¶

  1. ¿Cómo se reparte la base de clientes entre perfiles de comportamiento claramente distintos?
  2. ¿Cuánto vale cada perfil (valor mensual estimado con precio de lista)?
  3. ¿Los perfiles reflejan comportamiento real o sólo diferencias en el tiempo de observación?
  4. ¿Dónde están las oportunidades de acción y qué límites tienen los datos para respaldarlas?
  5. ¿Conviene empujar a los clientes mensuales hacia el plan anual?

Enfoque: segmentación conductual basada en reglas¶

El dataset no tiene atributos demográficos, geográficos ni de canal: sólo el recorrido de planes de cada cliente. Por eso la segmentación se define por comportamiento:

  • Estado al corte (cancelado o activo), plan vigente y trayectoria (entró directo a ese plan o llegó mejorando de plan).
  • Los 7 segmentos son mutuamente excluyentes y exhaustivos: cada cliente pertenece a uno y sólo uno.
  • Por qué reglas y no clustering: las variables disponibles son casi todas categóricas (plan, trayectoria, estado); un algoritmo de agrupamiento sólo reproduciría los planes y haría más difícil explicar y actuar sobre cada grupo. Las reglas dan segmentos interpretables y accionables.
  • Alcance: los segmentos de clientes que cancelaron se definen por su desenlace, por lo que sirven para describir y dimensionar, no para predecir quién cancelará.

Glosario¶

Los datos conservan los nombres originales en inglés; aquí se muestran en español.

Reglas de lectura (heredadas)¶

  • Valor estimado = precio de lista; el plan anual se expresa como equivalente mensual (precio ÷ 12). No son pagos reales.
  • Advertencias A1 y A2 siguen vigentes (anuales vencidos sin evento tratados como activos; sin eventos tardíos en planes mensuales).
  • Rigor: una diferencia sólo se presenta como hallazgo si supera un test estadístico (α = 0,05).

# Método A: reglas sobre las columnas derivadas
def segmento_a(r):
    if r["is_churned"] and not r["converted_to_paid"]:
        return SEGMENTOS[0]
    if r["is_churned"]:
        return SEGMENTOS[1]
    if r["current_plan"] == "basic monthly":
        return SEGMENTOS[2]
    if r["current_plan"] == "pro monthly":
        return SEGMENTOS[3] if r["first_paid_plan"] == "pro monthly" else SEGMENTOS[4]
    return SEGMENTOS[5] if r["first_paid_plan"] == "pro annual" else SEGMENTOS[6]

# Método B: reglas sobre el texto del recorrido (plan_path)
def segmento_b(path):
    pasos = path.split(" > ")
    if pasos[-1] == "churn":
        return SEGMENTOS[0] if pasos == ["trial", "churn"] else SEGMENTOS[1]
    if pasos[-1] == "basic monthly":
        return SEGMENTOS[2]
    if pasos[-1] == "pro monthly":
        return SEGMENTOS[3] if len(pasos) == 2 else SEGMENTOS[4]
    return SEGMENTOS[5] if len(pasos) == 2 else SEGMENTOS[6]

customers["segmento"] = customers.apply(segmento_a, axis=1)
seg_b = customers["plan_path"].map(segmento_b)

assert (customers["segmento"] == seg_b).all(), "Los dos métodos asignan segmentos distintos"
assert customers["segmento"].notna().all() and set(customers["segmento"]) == set(SEGMENTOS)       # exhaustivo
assert customers["segmento"].map(customers["segmento"].value_counts()).gt(0).all() and len(customers) == 1000   # cada cliente en uno solo
customers["grupo"] = customers["segmento"].map(GRUPO)
print("✔ Los dos métodos independientes asignan el mismo segmento a los 1.000 clientes.")

4. Validez: ¿son segmentos de comportamiento o de tiempo?¶

Una segmentación por trayectoria podría ser un espejismo: quien lleva más tiempo en la base tuvo más oportunidades de mejorar de plan. Se revisa con dos controles: (1) la antigüedad como pagador de los segmentos activos y (2) la composición por cohorte de cada segmento.

6. ¿Conviene empujar el plan anual? Análisis de equilibrio¶

A precio de lista, el equivalente mensual del plan anual es menor que el del Pro mensual (un descuento implícito). Entonces, pasar un cliente al anual baja el valor mensual por cliente. La pregunta correcta es otra: ¿cuánto ingreso esperable se asegura el negocio en 12 meses frente a seguir con un plan mensual que se puede cancelar?

Cálculo ilustrativo (supuestos explícitos):

  • Un cliente Pro mensual paga al inicio de cada mes y cancela con una probabilidad mensual h (tasa constante).
  • El plan anual paga el precio completo por adelantado, sin reembolsos.
  • Se usa la tasa de cancelación observada en el notebook 03 (entre el mínimo y el máximo de los intervalos de 30 días).
  • Se ignora lo que ocurra después de los 12 meses (la renovación del anual no se conoce, A1) y se acepta que la tasa constante es una aproximación (A2).

P_MENSUAL = val_pm                               # precio de lista Pro mensual (por mes)
P_ANUAL = val_an * 12                            # precio de lista Pro anual (por año)
desc_anual = 1 - val_an / val_pm

def ingreso_esperado_12m(h, precio=P_MENSUAL):
    # ingreso esperable en 12 meses de un cliente mensual que paga al inicio de cada mes y cancela con prob. h antes del siguiente pago
    return sum(precio * (1 - h) ** k for k in range(12))

# Control contra casos calculables a mano: sin cancelación son 12 pagos completos; con h=100 % sólo el primer pago
assert np.isclose(ingreso_esperado_12m(0.0), 12 * P_MENSUAL) and np.isclose(ingreso_esperado_12m(1.0), P_MENSUAL)

h_obs = np.array(m03["tasa_intervalo_30d"])
h_min, h_med, h_max = h_obs.min(), h_obs.mean(), h_obs.max()
h_equilibrio = optimize.brentq(lambda h: ingreso_esperado_12m(h) - P_ANUAL, 0.001, 0.2)
ventaja = lambda h: P_ANUAL / ingreso_esperado_12m(h) - 1

tabla_eq = pd.DataFrame({
    "escenario": ["Cancelación mensual mínima observada", "Cancelación mensual promedio observada", "Cancelación mensual máxima observada"],
    "tasa mensual": [h_min, h_med, h_max],
    "ingreso esperado a 12 meses (mensual)": [ingreso_esperado_12m(h) for h in (h_min, h_med, h_max)],
    "ingreso a 12 meses (anual)": [P_ANUAL] * 3,
    "ventaja del anual": [ventaja(h) for h in (h_min, h_med, h_max)],

9. Limitaciones y próximos pasos¶

Qué NO permite concluir este análisis

  • Sin variables de perfil: no hay edad, país, canal ni uso del servicio; los segmentos describen trayectoria, no personas.
  • Segmentos de cancelados definidos por el desenlace: no sirven para predecir quién cancelará.
  • Valor estimado: precio de lista, sin descuentos ni reembolsos; la moneda no está especificada.
  • Análisis de equilibrio del anual: es ilustrativo; supone tasa constante, pago al inicio de cada mes y no incluye la renovación (desconocida por A1) ni el comportamiento más allá de los 6 meses (A2).
  • Dimensionamiento de oportunidades: aritmética con precios de lista; no estima cuántos clientes aceptarían una propuesta ni su efecto causal.
